Google Drive · Optional Event Mirror

Hostinger remains the private QR and guest-download authority. Google Drive is an additional organizer-controlled copy of verified recordings, NOT a direct guest QR destination. Google sign-in and existing-folder picking open in a separate SYSTEM BROWSER tab, never inside Android WebView.

Sign in to view Drive configuration.

Select an Event to manage its Drive copy.

Each enabled event gets its own subfolder named with the Event title and stable ID. New ready videos are copied by the PRIVATE PHP cron worker; source recordings and ZIP delivery remain on Hostinger. Event folders are created on the next cron run, even before recordings exist. Existing event folders stay where they were when you change the base folder.

Privacy: Drive mirrors include ALL verified recordings, even videos Hidden from slideshow. Parent-folder sharing permissions are inherited. Guest Delete revokes Hostinger access immediately; deleting a Drive copy requires the scheduled worker and can be delayed. Never use a publicly shared base folder.

Disconnect stops new uploads/deletion requests but does NOT remove already-uploaded files from Google Drive. Reconnect the SAME account to finish deletion jobs; manually audit files before deleting an event or removing credentials.

Client delivery · Private ZIP archive

After the event, CLOSE new QR reservations, leave uploads open until all videos finish syncing, then CLOSE upload drain. Prepare a verified, immutable ZIP snapshot. Videos remain stored privately by Event ID; only verified, non-deleted videos enter the ZIP. Even clips hidden from the slideshow are included when you explicitly share all ready recordings.

Select an event to check archive status.

Preparing a ZIP queues a server-side job. Configure the private PHP CLI archive worker in Hostinger Cron. For large events the worker splits the download into several independent ZIP files (not multi-volume ZIP). Existing old client links are revoked when a new snapshot starts.

The client receives a private download link, not Cloud Admin access. Revoking a link blocks NEW downloads; any already downloaded copies cannot be recalled. Do not publish this link. One event ZIP may occupy approximately the same storage space as its videos.
