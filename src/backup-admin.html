交 USB 前必做： 完成所有錄影，確保數量全部顯示 verified，再按 Verify all，並實際喺電腦開啟幾段影片播放。若拔走 USB、冇空間、寫入失敗或程序中斷，原本 App 內影片唔會被移除；重新插入後按 Copy pending clips 補回。不要錄影途中拔 USB。

只備份真正錄影影片（WebM／MP4），唔會複製私密 QR、Cloud device secrets 或 Demo 模擬片。USB 上嘅獨立影片唔受雲端撤銷、Guest Delete 或 App 刪片控制；請取得活動主辦方授權、妥善保管及安全交付。USB 備份唔係雲端同步；Windows／一般網頁版不支援自動 USB 資料夾寫入。
